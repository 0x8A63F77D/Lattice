# #206 / #216 alignment contract — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development — one
> fresh subagent per task, a review between tasks, never inline execution in the controlling
> context. Steps use checkbox (`- [ ]`) syntax. Every task names its subagent `model` explicitly.

**Goal.** Implement RULING #206 (`docs/design/alignment/RULING.md`, merged in PR #217) — R1 cap-band
seating with metric cap height, per-class face selection, a top-anchored baseline and a
content-independent label box; R2's cap-height legend swatch; R3 unchanged — and the gates it
requires, as a ladder of small PRs. #216 (CJK collapse defect) and #204 (Statistics overflow row)
resolve inside the same ladder.

**Authority.** `RULING.md` is the contract and wins over everything here, including this plan.
`docs/design/alignment/README.md` is its handoff companion (RULING wins on disagreement); the other
files in that directory are historical evidence, not specs. Where this plan derives a requirement
the contract does not state in so many words, the derivation cites the clause it comes from
(§2.6, §4.7). Nothing here reinterprets a clause; a slice that finds a clause unimplementable as
written escalates (§10) instead of adapting it.

**Shape.** One mechanism: a `TextBlock` subclass, `BandLabel`, whose box, baseline and layout
slot are computed by a pure F# module (`LabelBand`, in `Lattice.App.Aggregation`) from ONE
`SKFontMetrics` read on ONE face. The mark is never touched: it stays a plain child centred by its
panel, and the label's layout slot is made to BE the band, exactly as the shipped mechanism does
with ink — only the source of the band changes. The swatch binds its size to the label's cap
height. Gates live in `tests/Lattice.VisualTests` and enumerate sites by the `BandLabel` type,
cross-checked by an independent structural census.

**Tech.** .NET 10, Avalonia 12.1.1 (+ Avalonia.Skia 12.1.1, SkiaSharp via it), FluentAvaloniaUI
3.0.2, F# + FsCheck.Xunit.v3 for the pure core, xunit v3 headless Skia for the gates.

**Granularity contract.** F# in §2.3 is normative — transcribe it (fix compile errors only;
report semantic doubts, do not redesign). C# in §2.4 is normative where marked **(normative)**,
contract-level elsewhere. Gate designs in §4 are normative in what they assert and how they decide;
helper structure is the implementer's.

**Slices (§7).** S1 metrics source + font registry → S2 core + `BandLabel` → S3 census + gate
harness → S4 localized chrome sites → S5 rail group header → S6 no-clipping check → S7 legend +
R2 → S8 overflow row (#204) → S9 retire the word-band machinery. S1–S3, S6, S9 are non-visual
(autonomous merge on a Codex-clean final commit + green CI). S4, S5, S7, S8 move pixels: the owner
signs each. Owner decisions needed before or during the ladder are collected in §9.

## 0. Facts this plan rests on (verified in the planning session, 2026-10-24)

Measured on Linux (this container, Avalonia 12.1.1 headless Skia, Inter embedded) or read from
the Avalonia `release/12.1.1` sources. Each is re-verified by the slice that depends on it.

- **F1 — Avalonia's line baseline follows content.** `TextLineImpl.CreateLineMetrics` takes
  `ascent = min(default face ascent, every shaped run's ascent)` (negative-up), `descent` and
  `lineGap` likewise as maxima over runs, then `baseline = −ascent + lineGap/2` (half the line gap
  ABOVE the ascent) and `height = descent − ascent + lineGap`. Measured: `"Rosetta@home"` in Inter
  12 px → line 14.523, baseline 11.625; `"Rosetta 国"` (Han falls back to WenQuanYi Zen Hei) →
  line 16.266, baseline 12.164. Liberation Sans: 13.799 / 11.060 → 16.195 / 12.094.
- **F2 — `TextBlock.LineHeight` does not fix it.** With `LineHeight ≤ natural`, Avalonia sets
  `baseline = −ascent` where `ascent` is still the max over runs (F1) — top-anchored on the
  CONTENT's tallest run, not the selected face. Above natural it centres (half-leading). Neither
  satisfies R1; stock layout cannot put the baseline at `labelBox.Top + A(selected face)` for a
  fallback-carrying string.
- **F3 — `TextBlock` exposes the two hooks that can.** `MeasureOverride` (protected override) and
  `RenderTextLayout(DrawingContext, Point origin)` (protected virtual) — `Render` itself is sealed.
  `TextLayout` keeps its first line even when it exceeds `MaxHeight`
  (`textLines.Count > 0 && Height + line.Height > MaxHeight` breaks only after the first line), so
  pinning the measured height cannot drop the text.
- **F4 — `SKFontMetrics` is reachable, but only through an internal type.**
  `GlyphTypeface.PlatformTypeface` is public; on the Skia backend it is `Avalonia.Skia.SkiaTypeface`,
  an **internal** class whose `SKTypeface` property is public. The public alternative,
  `IPlatformTypeface.TryGetStream`, returns the WHOLE font file: for a collection member it loads
  index 0 — measured, `WenQuanYi Zen Hei Mono` through the stream reads as `WenQuanYi Zen Hei`
  (cap 8.2344 instead of 8.9844). `Microsoft YaHei` / `Microsoft YaHei UI` (one `msyh.ttc`) and
  `PingFang SC` (a member of `PingFang.ttc`) are exactly this case, so the stream route is wrong
  for three registered faces.
- **F5 — cap height is hinting-sensitive; ascent/descent are not.** `SKFont` with default hinting
  reported DejaVu Sans 12 px cap 9.000 / x 7.000; with `Hinting = None` 8.750 / 6.5625. Inter,
  Liberation Sans and WenQuanYi were identical either way. The metric read must pin
  `Hinting = None, Subpixel = true, LinearMetrics = true`.
- **F6 — on FreeType, Avalonia's `FontMetrics` equals `SKFontMetrics`** for ascent / descent /
  line gap (Inter, DejaVu, Liberation, WenQuanYi). Not guaranteed on CoreText / DirectWrite and not
  relied on: the contract pins one struct, so `LabelBand` never reads Avalonia's `FontMetrics`.
- **F7 — metric cap height equals "H" ink in Latin faces.** Inter 8.7273 vs 8.728; Liberation
  8.256 vs 8.256; DejaVu 8.750 vs 8.748 (12 px). Helvetica: README gives ink 8.607; its OS/2 cap
  (717/1000 em) is 8.604 — S1 reads the real value on the macOS runner.
- **F8 — fallback is culture-scored.** `TextCharacters` resolves fallback with
  `FontManager.TryMatchCharacter(..., defaultTypeface.FontFamily, defaultProperties.CultureInfo,
  ...)`. "The face the stack resolves for the script" therefore depends on run culture as well as
  on the stack, which is why §2.5 resolves it by shaping, not by re-implementing the lookup.
- **F9 — no committed screenshot baseline contains an in-class site.** The 21 `*.verified.png`
  are `FirstRunViewVisualTests` ×2 (its 24 px hero icon is stacked above its caption — outside the
  scope boundary) and `StatisticsChartSnapshotTests` ×19, which render LiveCharts' own
  `SKCartesianChart` with no Avalonia chrome, so no legend chip. Nothing in this ladder rebaselines.
- **F10 — CI.** `ci.yml` runs `dotnet build -warnaserror` + `dotnet test Lattice.sln` on
  `ubuntu-latest`, `windows-latest`, `macos-latest`; the alignment gates are NOT env-gated, so they
  run on all three. `visual-tests.yml` runs `Lattice.VisualTests` on `macos-latest` with
  `LATTICE_RUN_VISUAL_TESTS=1`, uploads `artifacts/visual/**` and `*.received.png` as
  `visual-artifacts-<run_id>`, and accepts `workflow_dispatch`. This container has Inter, DejaVu,
  Liberation, WenQuanYi Zen Hei — no Helvetica, PingFang SC, YaHei or Noto Sans SC.
- **F11 — the ruling's "both edges" premise does not hold in Inter.** RULING says a fallback run
  "overflows the normalized box at both edges". Inter's box is 11.625 + 2.898 at 12 px; a Han
  glyph's ink spans −9.34…+1.45 around the baseline (WenQuanYi) — inside the box at both edges.
  In Helvetica (ascent ≈ 0.77 em) Han overflows the top but not the bottom. The PROPERTY (ink
  complete over the whole region above and below) is unaffected and stays the requirement; only
  the premise that ordinary Han text exercises both edges is false, so §4.8 builds samples that
  overflow both edges by construction. Reported to the controller, not escalated: no normative
  clause depends on the premise.

## 2. Mechanism

### 2.1 Options weighed (failure-mode-locality razor)

The razor compares failure modes, not elegance: riskable logic goes into pure functions plugged
into the framework's own extension points; chrome the framework provides is not hand-built.

| Option | What it is | Failure mode |
|---|---|---|
| A. Stock `TextBlock` + style (`LineHeight` = A+D, collapse `Margin` from metrics) | No new control | Wrong by construction for fallback content (F2): the drawn baseline sits on the tallest run's ascent, so a Han-carrying project name drops ~3 px below a Latin one in Helvetica. Violates "overflow never moves the baseline". A geometry gate on the BAND would still pass — the defect hides in render |
| **B. `BandLabel : TextBlock` overriding `MeasureOverride` (height) + `RenderTextLayout` (origin)** | Two framework hooks (F3); geometry in a pure F# function | The subclass is the only owned surface. Its risks — style-key matching, padding rounding, inline content — are each checkable in one headless assertion |
| C. Custom control drawing a `TextLayout` itself | Full ownership of text rendering | Re-implements trimming, decorations, foreground inheritance, automation — chrome the framework already provides. Rejected by the razor |
| D. Per-mark offsets (`Margin(0,d,0,−d)` on each mark) | Label left alone | The lab rejected it (#206 comment): N marks, N levers; not one mechanism |

**Chosen: B.** It is the smallest owned surface that can satisfy F1/F2, it keeps the shipped
architecture (label slot = band; marks centred by their panel, untouched), and every number it
uses comes from one pure function with exhaustive property tests.

### 2.2 Assembly and language boundary

- **Pure geometry and face-selection rule → F#, `src/Lattice.App.Aggregation/LabelBand.fs`.**
  It is App-layer pure logic with no UI dependency, which is what that assembly is for; it gets
  FsCheck properties and a DU-total match on the label class; and F# keeps the "one struct in, all
  geometry out" shape honest by construction (private representation, `Result` at the boundary).
  It is generic over the face type, so it never sees a font object.
- **The control, the metrics adapter and the face resolver → C#, `src/Lattice.App/Views/`.**
  XAML-facing types, Avalonia/Skia interop and the reflection adapter stay in C# (F# rules:
  "keep UI, XAML-facing types in C#").
- **Stryker:** out of scope (F# and Avalonia projects are both outside its reach); the
  falsification lists in §7 are the mutation evidence, executed by hand and repeated by reviewers.

### 2.3 `LabelBand.fs` (normative)

Add `<Compile Include="LabelBand.fs" />` after `ControlConfirmation.fs` in
`Lattice.App.Aggregation.fsproj`.

```fsharp
namespace Lattice.App.Aggregation

/// RULING #206 (docs/design/alignment/RULING.md) R1 + R2 as arithmetic: everything a mark-beside-
/// label site needs, computed from ONE metrics read on ONE face at the label's resolved size.
///
/// Coordinates are DIPs relative to the label box top, y growing downward. The module never sees a
/// font: the caller resolves the face (R1 "Face selection") and reads its SKFontMetrics; this
/// module only decides which face (`selectFace`) and what follows from its metrics (`geometry`).
module LabelBand =

    /// R1 "Face selection ... resolved per label class".
    type LabelClass =
        /// Chrome text from the resolved resource set. The metric face is the face the label's
        /// stack resolves for that resource set's SCRIPT, read off a fixed reference string of the
        /// set — never off the live label.
        | Localized
        /// Script unknown: project names and the figures beside them. The metric face is the
        /// stack's PRIMARY face, whatever the content.
        | UserData

    /// Why a metrics read was refused. Data for the gate's failure message; the shell degrades
    /// to plain TextBlock layout on any of them and the gate reports the site.
    type MetricsError =
        | NonFinite
        | NoAscent
        | NoCapHeight

    /// One SKFontMetrics read as magnitudes, in DIPs at the resolved size. The representation is
    /// private, so every FaceMetrics in existence passed `metrics` and is finite with A, C > 0.
    [<NoComparison>]
    type FaceMetrics =
        private
            { ascent: float
              descent: float
              capHeight: float }

        member m.Ascent = m.ascent
        member m.Descent = m.descent
        member m.CapHeight = m.capHeight

    /// From the raw SKFontMetrics fields, Skia's signs (Ascent ≤ 0, Descent ≥ 0). Magnitudes are
    /// taken here, once: RULING writes |ascent| and |descent|.
    let metrics (skAscent: float) (skDescent: float) (skCapHeight: float) : Result<FaceMetrics, MetricsError> =
        let finite v = not (System.Double.IsNaN v || System.Double.IsInfinity v)

        if not (List.forall finite [ skAscent; skDescent; skCapHeight ]) then Error NonFinite
        elif abs skAscent = 0.0 then Error NoAscent
        elif skCapHeight <= 0.0 then Error NoCapHeight
        else
            Ok
                { ascent = abs skAscent
                  descent = abs skDescent
                  capHeight = skCapHeight }

    /// R1, relative to the label box top.
    type Geometry =
        { /// labelBox.Height = |ascent| + |descent|. Line gap is outside the geometry.
          BoxHeight: float
          /// baseline − labelBox.Top = A(face, size). Top-anchored; nothing above the ascent.
          Baseline: float
          /// bandTop − labelBox.Top = baseline − capHeight.
          BandTop: float }

        /// bandBottom = baseline.
        member g.BandBottom = g.Baseline
        /// centerY(mark) = baseline − capHeight / 2.
        member g.BandCentre = (g.BandTop + g.Baseline) / 2.0

    let geometry (m: FaceMetrics) : Geometry =
        { BoxHeight = m.Ascent + m.Descent
          Baseline = m.Ascent
          BandTop = m.Ascent - m.CapHeight }

    /// How far the label's layout SLOT is inset from its box, (above, below), so that the slot IS
    /// the band. A panel that centres the slot then centres the band, and every mark it centres
    /// beside the label lands on the band with no lever of its own. Applied as a negative margin.
    let slotInsets (g: Geometry) : float * float = g.BandTop, g.BoxHeight - g.BandBottom

    /// Where the text must be drawn so its baseline lands on the geometry's, given the baseline
    /// the shaped layout reports for its first line (content-dependent, F1). The result is the
    /// layout's draw origin relative to the box top: the live baseline is cancelled, not used.
    let drawOrigin (g: Geometry) (layoutBaseline: float) : float = g.Baseline - layoutBaseline

    /// R2: the swatch box IS the band — side capHeight; its edges are BandTop and BandBottom.
    let swatchSide (m: FaceMetrics) : float = m.CapHeight

    /// R2: cornerRadius = 2 (= borderRadiusSmall).
    [<Literal>]
    let SwatchCornerRadius = 2.0

    /// One shaped run of the reference string, in logical order: the face that shaped it and
    /// whether its text carries the script (a letter of any case or a CJK ideograph — not a
    /// digit, space or punctuation, which every script shares).
    type ShapedRun<'face> = { Face: 'face; CarriesScript: bool }

    /// R1 face selection. `primary` is the stack's primary face; `reference` is the resolved
    /// resource set's fixed reference string, shaped in the label's typeface and size.
    /// UserData never looks at the reference; Localized takes the first script-bearing run's face
    /// (the fallback face when the primary lacks the script), and the primary when no run carries
    /// script (a degenerate reference — nothing to follow).
    let selectFace (labelClass: LabelClass) (primary: 'face) (reference: ShapedRun<'face> list) : 'face =
        match labelClass with
        | UserData -> primary
        | Localized ->
            reference
            |> List.tryFind _.CarriesScript
            |> Option.map _.Face
            |> Option.defaultValue primary
```

**`BandFace` (contract-level, with normative rules).**

- `Resolve(BandLabelRole role, Typeface typeface, double size) → Result<FaceMetrics, string>`:
  - `primary` = `typeface.GlyphTypeface`. Substitution check: expand the typeface's stack into
    the family names it can legitimately resolve to, then refuse when `primary.FamilyName` is
    none of them (the font manager substituted silently — the existing gates' `Resolve` lesson).
    The expansion is where aliases resolve, and it is load-bearing: Lattice pins no app font, so
    every production label inherits `FontFamily.Default` (`$Default`), whose glyph typeface
    reports a CONCRETE name (Helvetica on macOS). `$Default` expands to
    `FontManager.Current.DefaultFontFamily`'s family names; an embedded-font URI
    (`fonts:Inter#Inter`, `avares://…#Inter`) expands to its `#` fragment; a plain name stays
    itself. Without the expansion every unpinned label would be "substituted" and degrade to plain
    layout (Codex P2 on this plan). The expansion is a pure function of the stack's names plus the
    default family's names; it is unit-tested with `$Default`, a URI, a plain name and a
    multi-family stack, and the gates include unmodified default-family labels (§4.6 `D`).
  - Reference runs: shape `Strings.TaskStateRunning` with a `TextLayout` in `typeface` at `size`
    (the same reference the shipped word band uses, for the reason `WordBandFor` documents —
    it is a string the resource set actually loaded); map each `ShapedTextRun` to
    `ShapedRun(run.GlyphRun.GlyphTypeface, run.Text.Span contains a char whose
    UnicodeCategory is a letter category)`.
  - `face = LabelBand.selectFace(class, primary, runs)`; metrics = `FaceMetricsSource.Read(face,
    size)`; `LabelBand.metrics`.
  - Cache by `(role, typeface, size, CultureInfo.CurrentUICulture.Name, CultureInfo.CurrentCulture.Name)`
    — UI-thread only, a plain `Dictionary`. The two culture names are in the key because the
    reference string follows the UI culture and fallback scoring follows run culture (F8).
- `FaceMetricsSource.Read(GlyphTypeface face, double size)` **(normative rules)**: the exact
  `SKTypeface` of `face` via `face.PlatformTypeface` → its public `SKTypeface` property, read by
  reflection on the internal `Avalonia.Skia.SkiaTypeface` (F4; decision D7). One
  `new SKFont(sk, (float)size) { Hinting = SKFontHinting.None, Subpixel = true, LinearMetrics = true }`
  → `GetFontMetrics` → `(Ascent, Descent, CapHeight)`. Never the stream route (F4), never a
  name-based `SKTypeface.FromFamilyName` (silent substitution). Anything else (no Skia backend —
  `Lattice.App.Tests` runs the fake drawing backend; reflection miss after an Avalonia bump) →
  `Error`, which the control turns into plain `TextBlock` layout and the VisualTests gate turns
  into a red site.

**`BandLabel` (normative behaviour, contract-level code).**

```csharp
/// RULING #206 R1 on one label: box = |A|+|D| of the selected face, baseline drawn at box top + A,
/// layout slot = the cap band. Plain Text only (no Inlines). Every consumer still owes
/// UseLayoutRounding="False" on the panel holding the pair (InkAlignmentStyles.axaml).
public sealed class BandLabel : TextBlock
{
    public static readonly StyledProperty<BandLabelRole> RoleProperty = ...;            // default Undeclared
    public static readonly DirectProperty<BandLabel, double> CapHeightProperty = ...;   // read-only; R2 binds to it
    public static readonly DirectProperty<BandLabel, Thickness> SlotMarginProperty = ...; // read-only

    // Existing TextBlock selectors (.numeric, .chipText, theme styles) must keep matching.
    protected override Type StyleKeyOverride => typeof(TextBlock);

    public BandLabel() => Classes.Add("bandLabel");   // the style below can never be forgotten

    // Recompute on Role, FontFamily, FontSize, FontWeight, FontStyle, FontStretch changes (all
    // inherited, so OnPropertyChanged sees inherited changes too) and on attach: resolve via
    // BandFace, store LabelBand.Geometry (or null), raise CapHeight / SlotMargin, InvalidateMeasure.
    // NOT inside MeasureOverride: raising a property the swatch is bound to mid-measure would
    // re-enter layout.

    protected override Size MeasureOverride(Size availableSize)
    {
        var natural = base.MeasureOverride(availableSize);
        return _geometry is { } g ? natural.WithHeight(g.BoxHeight + VerticalPadding) : natural;
    }

    protected override void RenderTextLayout(DrawingContext context, Point origin)
    {
        if (_geometry is { } g && TextLayout.TextLines is [var first, ..])
            origin = origin.WithY(TopPadding + LabelBand.drawOrigin(g, first.Baseline));
        base.RenderTextLayout(context, origin);
    }

    /// For the gate only: the y at which the first line's baseline is drawn, relative to Bounds.
    internal double DrawnBaselineY => ...;   // the SAME expression RenderTextLayout uses + first.Baseline
}
```

`VerticalPadding` / `TopPadding` use `LayoutHelper.RoundLayoutThickness` exactly when the base
class does (when `UseLayoutRounding`), so the subclass and base never disagree about padding.
`CapHeight` is the selected face's cap height, or 12 when there is no geometry — today's swatch side,
so a degraded swatch is not invisible (the gate still fails the site).

### 4.2 The contract gate (S3 harness, sites from S4 on)

For every `BandLabel` L found by marker enumeration (§4.3), in every site-fixture surface, for
every font configuration (§4.6) and culture configuration (§4.6), at render scaling 1:

1. Expected face `F` from the CONFIGURATION TABLE (§4.6), not from production code; expected
   metrics `(A, D, C)` = `FaceMetricsOracle(F, L.FontSize)`.
2. `|L.Bounds.Height − (A + D)| ≤ 0.05` — RULING (a).
3. `top` = L's window-space `Bounds` top; `baseline = top + A`; `bandTop = baseline − C`;
   `bandCentre = baseline − C/2`.
4. For every mark M in L's container (the `MarkOf` glyph box, #212's helper — a CheckBox
   resolves to its 20 × 20 painted square): `|centreY(M) − bandCentre| ≤ 0.05`. A container with
   two marks (Computing) asserts both against the same band.
5. Drawn baseline (§2.6): `|top + L.DrawnBaselineY − baseline| ≤ 0.05`.
6. R2, where the container holds a `.bandSwatch` S: `|S.Height − C|`, `|S.Width − C|`,
   `|S.top − bandTop|`, `|S.bottom − baseline|` ≤ 0.05, and every corner of every child `Border`
   `== 2`.
7. Metrics present: a `BandLabel` whose `BandFace` returned an error fails with the error, and a
   `Role == Undeclared` label fails.

The ABSOLUTE expectation (steps 1–3) is what RULING demands over mark-to-band consistency: the
band is computed from `(A, C)` of the expected face, so a bottom-anchored or half-leading
implementation, or one reading the wrong face, fails step 4 or 5 even if it is self-consistent.

Rendered layer (kept from today's gates, 1× and 2×): each mark's painted ink centre and the label's
painted ink centre are where the arranged geometry says, within `InkAlignment.MaxInkDeviationDip`
(two device pixels — hinting, not layout, sets it). The label probe uses a cap-flat sample whose
ink bottom IS the baseline, so the rendered layer also checks the drawn baseline end to end.

### 4.8 The no-clipping rendered-ink check (S6) — RULING acceptance criteria 1–4

**Property (RULING).** At every registered user-data site, under a fallback-forcing mixed-script
sample, the label's own rendered ink is complete: identical to that label's ink with clipping
removed from its entire ancestor chain, over the whole overflow region, above the box top and below
the box bottom.

**Construction.** `InkCompleteness.Check(Window window, BandLabel target) → Verdict`:

1. **Chain.** `target`'s visual ancestors up to its `TopLevel` (a popup's chain ends at the popup
   root).
2. **Clip audit (criterion 4).** Each ancestor's clipping must be one of: `ClipToBounds`, a
   `Clip` geometry, or a TopLevel / popup surface edge. An ancestor of a type on no audited
   allowlist (`ClipAuditedTypes`, built in S6 by reading the Avalonia/FA render code of every type
   that occurs in a registered chain, recording which call `PushClip` and why) ⇒
   `Verdict.Escalate(site, type)`: the test fails with "unhandled clipping source", which per
   RULING is an escalation, not a silent drop. A surface edge cannot be removed; it is handled by
   containment — the declipped ink's bounding box must lie inside the surface, else `Escalate`.
3. **Isolation (criterion 2).** For the duration of the check, through disposable
   `BindingPriority.Animation` overrides (the transitions-detach idiom; restores whatever local
   and style values were there):
   - `Opacity = 0` on every visual that is neither in the chain, nor `target`, nor its
     descendants — siblings and their subtrees paint nothing, so no sibling ink can be revealed,
     occluded or blended;
   - `target.Foreground` = sentinel `#FF00FF`, so the target's ink differs from any background.
   None of these changes layout.
4. **Masks.** In each of two configurations — REAL (clips as shipped) and FREE (every chain
   ancestor `ClipToBounds = false`, `Clip = null`, same override mechanism) — render twice:
   target `Opacity = 1` and target `Opacity = 0`. The target's ink mask is the set of pixels whose
   RGBA differs between the two. Ancestor paint (backgrounds, rounded borders) is identical in the
   pair and cancels; only the target's own ink survives.
5. **Verdict (criterion 1).** `mask(REAL) == mask(FREE)` over the WHOLE frame, pixel-exact, and
   the RGBA inside the mask equal ⇒ `Complete`; otherwise `Violation` reporting differing pixels
   above the box top, inside the box and below the box bottom. Whole-frame comparison covers the
   whole overflow region by construction; both renders share hinting, snapping and AA, so no
   tolerance is needed. A determinism self-check renders REAL/Opacity=0 twice and requires
   identity — a nondeterministic renderer is a harness error, reported as such, never a pass.
6. **Non-vacuity.** `mask(FREE)` must contain ink above the box top AND below the box bottom for
   the mixed sample (§4.5), at every site, in every present font configuration. The stacked
   combining marks are chosen so this holds (Inter covers them; other primaries cover them or
   fall back), but the check verifies it per configuration instead of assuming it: where it does
   not hold, the edge was not exercised — failure, not pass.

Run at: legend chip name (each chip), overflow name, overflow RAC (co-label, §6) × every present
font configuration × {1×, 2×} × {light, dark}, under the mixed sample.

**Falsification (criterion 3), committed as tests.** `NoClippingCheckFalsificationTests` runs a
synthetic scene host — `Window > Border(outer, CornerRadius 6, Background) > StackPanel
(UseLayoutRounding=False) > [12 px swatch mark, BandLabel(UserData, mixed sample), sibling
TextBlock with its own stacked marks]` — through the real check AND through committed strawman
variants of it, and asserts a verdict table:

| Scene | Truth | Real check | Strawman that disagrees (proves discrimination) |
|---|---|---|---|
| T1 `Clip` on the panel: rect from box top down (cuts only ink above the box) | violation | red | `BelowOnly`, `BoxOnly` → green |
| T2 `Clip` on the panel: rect down to box bottom (cuts only ink below) | violation | red | `AboveOnly`, `BoxOnly` → green |
| T3 `ClipToBounds` on the OUTER border sized tight around the box (a grandparent) | violation | red | `ParentOnlyDeclip` → green |
| T4 `Clip` cutting a vertical strip through the box | violation | red | `AboveOnly`, `BelowOnly` → green |
| N1 sibling's marks overflow and are clipped by the panel; target's ink untouched | complete | green | `WholeFrame` → red |
| N2 outer border's rounded content clip (`ClipToBounds` + `CornerRadius`) cuts its own background corners and the swatch's corner, not the target | complete | green | `WholeFrame` → red |
| N3 an ancestor background larger than its parent's clip, revealed by declipping | complete | green | `NoToggle` (compares frames, no opacity pair) → red |
| N4 a sibling drawn ABOVE the target overlaps the target's overflow ink and is clipped away in REAL only | complete | green | `NoSuppression` → red |
| E1 a chain ancestor of an unaudited type that clips in render | — | `Escalate` | — |

The suite also asserts that every strawman disagrees with truth on at least one scene — a
strawman that agrees everywhere would make its rows non-evidence — and that the real check agrees
with truth on every scene. Strawmen live in the test project only (`InkCompletenessVariants`),
built from the real check by removing one step each, so each row is a falsification of one
specific step: `BoxOnly` / `AboveOnly` / `BelowOnly` restrict step 5's region, `ParentOnlyDeclip`
restricts step 4's FREE to the parent, `WholeFrame` drops steps 3–4, `NoToggle` drops the opacity
pair, `NoSuppression` drops the sibling override.

Red-first on real code (S6's PR evidence, not committed): inject `ClipToBounds="True"` on the
legend chip's StackPanel (whose height is the band, so it cuts above and below) → red at the legend
site in every font; inject the same on the overflow row's Grid → red there. Both reverted.

**D1 — Commit Noto Sans SC as a test-only font (new dependency).** Recommended: commit the
static Regular `NotoSansSC-Regular` (SIL OFL 1.1, with its licence text) into
`tests/Lattice.VisualTests/Assets/Fonts/`, embedded in the test assembly only. Exact size measured
in S1 (order of 10 MB). (a) Users see nothing — it never ships in the app. CI gates the registered
Linux CJK face on every OS, and the fallback paths (§4.7, §4.8) get a CJK face whose ascent
exceeds Inter's on every runner, so the drawn-baseline mutant dies everywhere instead of only on

a middle way, at the price of a one-time proof that subsetting kept the vertical metrics.
(c) Wrong if S1 shows the Ubuntu runner already ships `Noto Sans SC` under that exact name, or if
the Noto Sans CJK SC metrics equal Noto Sans SC's to 1e-3 at every size (then the apt route gates

minimum is a constant that exists only to preserve an old size that was itself an accident of the

legend denser, which the design direction favours. (c) Wrong if the side-by-side captures in S7
show the shorter chip reads better to the owner's eye.
